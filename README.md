# 三國字｜亂世一生

手機直式文字人生遊戲，採米紙、深木、墨色、朱印與暗金古風。

此版本包含 2026 年 10 月 17 日第二批手機回饋修訂。遊戲完全在瀏覽器執行，無 AI 功能，提供 5 格手動存檔與 1 格自動存檔。

## 本機執行

在此目錄執行 `python3 -m http.server 8765`，然後開啟 http://127.0.0.1:8765/ 。

## GitHub Pages

到儲存庫 Settings → Pages，選擇 Deploy from a branch、main、/(root)，再按 Save。此目錄可以直接發佈，無須建置。

## 存檔

存檔保存在目前瀏覽器及網站網址下。更換網址或瀏覽器時，舊網址的存檔不會自動搬移。目前尚未提供跨網址搬移存檔功能，原網址的存檔仍保留在原瀏覽器。
